# 让AI智能体参与到大学生竞赛项目中

大家好呀！这个仓库面向参与大创、挑战杯等项目的中国大学生，收录了两份从实际项目协作中整理出来的中文提示词。适合搭配 Codex、Claude Code 等能够读写本地文件的 AI 智能体使用，不限定具体工具，也不要求模型在本地运行。

做一个持续几个月的项目，除了写材料，还要整理资料、维护版本、记录进度。随着文件和对话越来越多，AI 容易忘记之前的要求，用错版本，或者把已经人工改好的内容重新改掉。这两份提示词就是把长期协作中反复强调的要求整理下来，减少重复解释，也让后续工作更容易接上。

[项目书写作通用提示词](项目书写作通用提示词.md)主要用于报名书、项目计划书、商业计划书和结项报告等材料的写作。它要求智能体先了解项目和已有资料，再组织内容，同时注意事实口径、文字表达、图表使用和模板格式，尊重已经完成的人工修改。

[长期项目组织与归档通用提示词](长期项目组织与归档通用提示词.md)主要用于整个项目的资料管理和持续协作，包括文件夹怎么安排、说明文件写多详细、版本如何保留，以及重要信息和决定如何记录。希望做到需要的资料找得到，当前进度看得明白，换一个对话或智能体也能继续工作。

使用时，可以先按自己的习惯调整提示词，再把文件交给智能体阅读，同时告诉它项目资料的位置、当前使用的版本和本次要做的事情。两份提示词可以单独使用，也可以配合使用，不必逐条照搬，更不需要为了使用它们重新整理整个项目。

这些内容是协作经验，不是比赛的官方要求，具体仍以学校通知和提交模板为准。AI 处理后的材料需要自己确认，尤其是数据、引用和成果状态；重要原件要留好，个人信息、合同和账号密钥也要注意保护。
